AI SOC Investigation Agent

Python ReAct Tool Calling Phi-3 Mini llama.cpp

A ReAct-based AI SOC investigation agent designed to analyze raw security events, identify suspicious authentication patterns, and enrich investigation findings using threat intelligence and MITRE ATT&CK mapping. The agent follows a structured Thought → Action → Observation loop to gather evidence before producing a security assessment.

View Repository on GitHub ↗
Agentic Investigation Architecture
▸ Raw Security Event Analysis: Analyzes original security events to identify suspicious authentication patterns and extract relevant evidence, including users, timestamps, source IPs, and event details.
▸ ReAct Reasoning Loop: Implements the Thought → Action → Observation pattern. The agent plans its next investigation step, selects an appropriate tool, and incorporates the returned observation into subsequent reasoning.
▸ Dynamic Tool Calling: Selects and executes investigation tools based on the current findings, allowing the agent to retrieve additional evidence during the investigation.
▸ Threat Intelligence Enrichment: Checks suspicious IP addresses against a local threat intelligence lookup dataset and retrieves reputation, confidence scores, and associated threat categories.
▸ MITRE ATT&CK Mapping: Searches for relevant ATT&CK techniques to determine whether the observed behavior is consistent with known adversary tactics and techniques.
▸ Evidence-Driven Assessment: Correlates log analysis, threat intelligence results, and MITRE ATT&CK mappings to produce structured findings. Distinguishes suspicious activity from confirmed compromise and provides a confidence assessment.

Investigation Tools
look_ips(ip)

Retrieves IP reputation information, confidence scores, and associated threat categories from the local lookup dataset.

search_mitre(query)

Searches the MITRE ATT&CK lookup dataset for techniques relevant to the observed behavior.

Final SOC Assessment
INVESTIGATION RESULT

Correlation

Four failed login attempts targeted different accounts (alice, bob, charlie, david) from the same IP address (91.204.17.33) within 21 seconds. Threat intelligence returned a suspicious reputation with a confidence score of 0.78 and a password_spraying category. MITRE ATT&CK returned T1110.003 (Password Spraying), consistent with the observed behavior.

Conflicts

No conflicts were identified between the log analysis, threat intelligence result, and MITRE ATT&CK mapping.

Assessment

Possible password spraying activity originating from 91.204.17.33. All observed login attempts failed, so no successful compromise is evident in the provided data.

Recommendations

Monitor or investigate the source IP, enforce MFA, and review account lockout policies.
