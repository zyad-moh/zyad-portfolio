Ask & Remember

LangChain LLM Agents Groq / Llama 3.3 Streamlit Python

A conversational research assistant engineered using LangChain's ReAct agent framework. It dynamically routes queries across target APIs while maintaining multi-turn memory to resolve complex follow-up context effortlessly.

View Repository on GitHub ↗
Agentic Execution Architecture
▸ ReAct Reasoning Loop: Drives multi-step cognitive processing using explicit Thought → Action → Observation tracking blocks, exposed to users via an interactive transparency console expansion layout.
▸ Multi-Tool Routing Fabric: Intelligently analyzes and switches routing paths across isolated toolkits (Weather APIs, Currency converters, Wikipedia indices, Math engines, and live Web Search engines).
▸ Short-Term Contextual Memory: Stores ongoing dialog states natively, parsing implicit contextual references (e.g., "convert that into EUR") without needing repeat baseline strings.
▸ Persistent Session Control: Serializes conversation graphs locally to ensure active chat history states reload perfectly between browser lifecycles.
